wComics is a simple comic viewer for iOS.

[![Available on the App Store](https://raw.githubusercontent.com/Brite-Apps/wComics/master/appstore.svg)](https://apps.apple.com/us/app/wcomics/id6476523177)

# Supported formats

* CBZ (ZIP)
* CBR (RAR)
* PDF

# Uploading

Comic files can be uploaded with any browser. Start the web server from application and connect to it using any browser.

Files can also be opened from your internal or cloud storage.
